# FlowX

[中文](README_zh.md)

A minimalist macOS menu bar lyrics viewer for **Apple Music**.

> 🚧 **Work in Progress** — Features are still under active development.

## Features

- **Real-time synced lyrics** displayed in the menu bar
- **TTML lyrics** fetched from Apple Music API with disk caching
- **Playback controls** (play/pause, previous, next) on hover
- **Multi-language** UI support (English, Simplified Chinese)

## Requirements

- macOS 26+
- Apple Music

## Tech Stack

- Swift 5 / SwiftUI + AppKit
- ScriptingBridge (Apple Music integration)
- Apple Music API (TTML lyrics)
