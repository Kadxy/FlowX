# FlowX

[English](README.md)

一个极简的 macOS 菜单栏歌词应用，专为 **Apple Music** 设计。

> 🚧 **开发中** — 功能尚在积极开发中。

## 功能

- 菜单栏**实时同步歌词**显示
- 从 Apple Music API 获取 **TTML 歌词**，支持磁盘缓存
- 鼠标悬停时显示**播放控制**（播放/暂停、上一曲、下一曲）
- **多语言** UI 支持（英文、简体中文）

## 系统要求

- macOS 26+
- Apple Music

## 技术栈

- Swift 5 / SwiftUI + AppKit
- ScriptingBridge（Apple Music 集成）
- Apple Music API（TTML 歌词）
